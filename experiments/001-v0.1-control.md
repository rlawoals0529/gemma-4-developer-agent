# v0.1 - single-agent control

Date: 2026-09-26

Starting point:
First measured version.

Question:
What does a plain single-agent setup score before adding routing, skills, reviewers or adapters?

Change:
One `LlmAgent`, all nine harness tools, no sub-agents, no custom skills, no LoRA adapters. Graph
and semantic tools were available but not mandatory. Sampling stayed close to the starter setup.

Result:
Local resolution rate: not recorded
Kaggle public score: **0.05**
Rank at submission time: not recorded

What this established:
The agent can produce valid submissions, but the control leaves a lot of room to improve issue
localization, feedback loops and context use.

Decision:
keep as the control, not as the final architecture

Next:
Try a stronger workflow, but keep the 0.05 score as the number later versions have to beat.
